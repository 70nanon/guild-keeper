# Guild Keeper デザインガイドライン

## 位置づけ

本書は、今後の UI・アセット開発で参照するビジュアルデザインの方針です。ゲームのルールは [GAME_DESIGN.md](GAME_DESIGN.md)、実装範囲・検証は [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)、機能の依存関係と進捗は [FEATURES.md](FEATURES.md) を参照してください。

本書は基本方針と採用記録を区別して管理します。v0.1 のリデザインで反映した内容は末尾の採用記録を参照してください。それ以外の構想の実装完了を意味しません。機能 ID・依存関係・完了チェック、MVP のゲームルールはデザイン変更では変更しません。

## デザインコンセプト

**「昔の牧歌的なファンタジー RPG に登場する、小さな村の冒険者ギルドの倉庫」**

村の日常、冒険の裏方、使い込まれた道具、温かい生活感を軸にします。1990年代の家庭用 RPG を連想させる素朴さと、どこか懐かしい雰囲気を目指します。木製の棚や道具箱に装備と薬瓶が並び、羊皮紙の注文書を見ながら冒険の支度を手伝う場所です。

重厚で高級なギルドや壮大な英雄譚を画面の主題にしません。特定作品の画面構成・ロゴ・キャラクター・素材をそのまま模倣せず、独自の表現にします。

## 世界観とゲーム体験の関係

素朴な倉庫の見せ方は、冒険を支える裏方の日常を伝えるために使います。「小さな村」は雰囲気の基準であり、在庫数・倉庫規模・将来の成長を制限する設定ではありません。規模が増しても、道具を使い、棚を整える生活感を保ちます。

次のゲームコンセプトを維持します。

- 大量のアイテムを探し、自由に整理する。
- 配置や作業方法を工夫し、効率化する。
- アップグレードや自動化によって成長する。
- 同じ倉庫を継続して管理する。
- 時間制限に追われず、自分のペースで遊ぶ。

## 判断の優先順位

1. アイテム・数量・注文条件・操作状態を読み取れること。
2. PC・スマホで探す、選ぶ、移す、納品する操作を快適に行えること。
3. 倉庫の一覧性と、整理した配置を見渡せること。
4. 上記を保ちながら、温かく素朴な世界観を伝えること。

装飾の追加で表示領域や識別性、応答性が悪くなる場合は、装飾を簡略化します。

## 配色方針

| 色の方向性 | 主な用途の候補 |
| --- | --- |
| 木材を連想させる茶色 | 倉庫の外枠、棚板、木札 |
| 羊皮紙のクリーム色 | 注文書、帳簿、読み物の面 |
| くすんだ草色 | 補助色、落ち着いた区切り |
| 柔らかい金色・真鍮色 | 小さな留め具、控えめなアクセント |
| 落ち着いた赤・青 | 必要に応じた状態や注意の区別 |

上表は基本方針です。v0.1 で採用したカラーコードと状態の割り当ては末尾の採用記録に示します。既存の深緑・金色の配色を維持する前提にはせず、新コンセプトと読みやすさに照らして再検討します。

画面全体を過度に暗くせず、文字・数量・アイコン・選択枠と背景のコントラストを確保します。落ち着いた色彩と低いコントラストを混同しません。選択、移動先、操作不可、完了やエラーは色だけで伝えず、枠・記号・ラベルなどを併用します。

## UI の素材感

| UI | 目指す素材感・意匠 |
| --- | --- |
| 倉庫 | 木箱や棚板を連想させる簡素な枠 |
| 注文書 | 羊皮紙、手書きの帳簿 |
| ボタン | 木札や素朴な道具 |
| 情報パネル | 革表紙の帳面、簡素な掲示板 |
| 小さな装飾 | 革の綴じ目、真鍮の留め具 |

素材感は薄い色差や簡素な縁取りでも表現できます。木目・紙の汚れ・傷は控えめにし、文字やアイコンの背後に強い模様を置きません。厚い額縁、巨大な金具、装飾のための余白でインベントリを狭くしないでください。手書きの雰囲気は帳簿の構成や罫線でも表現でき、本文を読みにくい手書き文字にする必要はありません。

## タイポグラフィ

- 見出しや短いラベルは、懐かしい RPG を感じる表現を検討できます。
- アイテム名、数量、注文条件、説明、操作ボタンは可読性を優先します。
- 日本語の漢字・かな、数字、英字が混在しても判読できる書体・大きさ・行間を選びます。
- スマホで文字を小さく詰め込みすぎず、名前の折り返しや拡大時も数量・ボタンが隠れないようにします。
- 装飾書体が日本語に対応しない場合も、代替書体で情報の階層が保たれるようにします。

v0.1 の書体・文字サイズは末尾の採用記録に示します。将来の独自の装飾書体は未決定です。外部フォントを採用する場合は、利用条件・日本語対応・読み込み負荷も確認します。

## アイテムアイコンの方針

- 昔の RPG 風の、小さく分かりやすいアイコンを目指します。適度にデフォルメし、素朴で統一感のある輪郭・陰影にします。
- 剣・盾・薬瓶・巻物などの種類は、色だけでなく形とシルエットで直感的に区別できるようにします。例示した品目を新しいゲームデータとして追加する指示ではありません。
- 小さいセルで実際に表示して確認し、細かな描き込みより識別性を優先します。数量や選択記号がアイコンを覆わないようにします。
- 品名や種類の文字情報を補助として残し、絵だけに識別を依存しません。
- 自作または利用条件を確認できる素材を使い、必要な出典・ライセンスを記録します。特定作品の画像や既存ゲーム素材を無断流用しません。

ピクセルアートは候補であり、必須ではありません。描画方式、制作・調達方法、解像度、表示サイズは実装前に検討します。本格的な制作・統一は既存の F-004 の範囲で扱い、MVP の仮アイコン利用を F-004 完了とはみなしません。

## UI レイアウトの原則

**ゲームの主役は常にインベントリです。装飾によってインベントリの表示領域を圧迫しないことを必須とします。**

- 画面の大部分を倉庫の一覧に使い、大量の品と整理の結果を見渡せるようにします。
- 注文書は品目・必要数・充足状況をコンパクトに示し、探索と照合を行き来しやすくします。
- 選択品の情報と操作欄は必要な情報に絞り、在庫セルや移動先を覆わない位置に置きます。
- 大きなロゴ、キャラクターの立ち絵、背景の村風景、装飾専用パネルを主画面の広い領域に置きません。
- 選択状態、移動モード、操作結果を区別し、次にできる操作を明確にします。装飾をクリック可能な操作と誤認させないようにします。
- 世界観のためにレイアウトや配置を勝手に変えず、既存の操作・整理結果を保ちます。

具体的な配置・セル寸法・表示密度は、PC とスマホで識別性と操作性を確認して決めます。

## アニメーション・演出

納品時の控えめなフィードバック、注文完了時の小さなスタンプ、品が棚に収まるような短く自然な動きが候補です。いずれも現時点で導入必須の演出ではありません。

- 操作結果がすぐ分かり、連続作業やスクロールを妨げないようにします。
- 演出完了を待たせず、アイテム名・数量・状態表示は動きがなくても分かるようにします。
- 長時間触っても疲れにくい、短く穏やかな表現にします。常時動く背景、点滅、画面揺れ、派手なパーティクル、過度な発光は避けます。
- 動きを減らす設定（`prefers-reduced-motion` など）を考慮し、動きを省いても情報が失われないようにします。

スタンプの意匠、動作時間、動きの種類は未決定です。演出だけを理由に未実装の納品・注文機能を先回りして追加しません。

## PC・スマホ対応

- PC のクリックとスマホのタップで一連の操作を完結できるようにし、ドラッグを必須にしません。
- ホバーだけに説明や主要操作を置かず、タップでも必要な情報を確認できるようにします。
- キーボードのフォーカスと選択状態を見分けられるようにし、装飾でフォーカス表示を消さないようにします。
- スマホ縦画面では注文書や操作欄を簡潔にまとめ、倉庫の表示領域と指で押せる操作対象を両立します。
- スクロールと選択・移動を混同させず、誤操作しにくい間隔を確保します。見た目の小ささに合わせてタップ領域を縮めません。
- 小さい画面・短い画面・文字の拡大でも、名前・数量・主要ボタンの欠けや不要な横スクロールがないか確認します。

## 避けたいデザイン

- 重厚で高級な城館、巨大な紋章、豪華すぎる金装飾。
- 壮大な英雄譚や戦闘を主題にした主画面。
- 過度に暗い画面、ネオンカラー、強い光沢や発光。
- 判読しづらい装飾書体、文字に重なる木目・汚れ、色だけによる品や状態の区別。
- 棚の装飾や常設パネルが倉庫を圧迫する構成。
- 派手なパーティクル、長い待ち時間、繰り返す画面演出。
- 特定作品の模倣や、権利を確認していない画像・フォント・素材の流用。

## MVP 段階で最低限反映する内容

以下は、MVP の UI を調整する際の最低限の適用基準です。v0.1 の適用内容と確認範囲は末尾の採用記録とレビュー記録に示します。

1. 木材の茶色・羊皮紙のクリーム色を軸とする落ち着いた面と簡素な枠で、小さな村の倉庫の雰囲気を伝えます。草色・真鍮色などのアクセントは少量に留めます。
2. 倉庫を主役にし、注文書・選択品・操作欄をコンパクトに配置します。装飾で一覧できる領域を減らしません。
3. 品名・数量・注文条件と選択・移動・完了の状態を読み取りやすくします。日本語表示と色以外の手掛かりを確保します。
4. 仮アイコンでも文字情報で品を識別できるようにします。本格的なアイコン、独自フォント、素材テクスチャ、スタンプ、アニメーションは MVP の最低条件に含めません。
5. PC・スマホでクリック／タップによる探索・選択・移動・納品を確認し、ドラッグ不要とスクロール時の操作性を保ちます。

具体色、書体、アイコンの描画方式、素材の作り込み、演出の採否は候補から検討し、採用時に本書へ記録します。デザイン適用の確認は機能バックログの完了チェックとは区別し、本書だけを根拠に機能の完了判定を変更しません。

## v0.1 リデザインでの採用記録

本節は MVP 画面への初回適用で採用した判断です。長期のアイコン制作や新機能の採用を意味しません。変更前後の画面と表示領域の検証は [レビュー記録](reviews/village-warehouse/README.md) を参照してください。

| 役割 | 採用色 |
| --- | --- |
| 画面の下地 | 温かい生成り `#e9e1ce` |
| 本文・補助文字 | 焦げ茶 `#423322`、落ち着いた茶 `#67583f` |
| 注文書の紙・紙端 | クリーム `#f5ecd3`、`#bba77d` |
| 棚・道具箱の枠 | 木色 `#936e49`〜`#8e6845`、濃い縁 `#69482f` |
| アイテム枠 | 淡い木色 `#eaddbe`〜`#e0cba4` |
| 選択・完了 | くすんだ草色 `#51613c`、淡い面 `#d9e1bd` |
| キーボードフォーカス | 青墨 `#244c5b` の輪郭とクリームの補助縁 |

- 注文書は薄い紙色のグラデーション、左端の細い綴じ目、品目ごとの控えめな罫線で帳簿を表現します。文字の下に紙の汚れや模様は置きません。
- 倉庫は既存の間隔を木製の仕切りに見立て、セルの下端に薄い影を付けて道具箱の素材感を表現します。棚のための新しい余白・枠領域は追加しません。
- 納品・次の注文・リプレイの主要ボタンは茶色の木札、補助操作は淡い草色で統一します。操作不可は落ち着いた無彩色寄りの面と文字で示します。
- 選択は草色の太枠とチェック、移動モードは破線と既存の説明、完了は既存のチェック・文言を維持します。キーボードフォーカスは青墨の外側輪郭で選択と区別します。
- 本文・品名・数量は既存のシステムフォントを維持します。ロゴは既存の Georgia と serif、注文の短い見出しだけローカルの明朝系／serif を使用します。フォントはダウンロードしません。
- 品名は PC 11px・スマホ10pxとし、セル内の左右余白を調整して名前を欠けさせず、表示できる列数を維持します。既存のセル寸法・列の最小幅・44px以上のタップ領域を保ちます。
- 画像テクスチャ・外部ライブラリ・外部フォント・追加アニメーションは導入せず、CSS の色面・縁・控えめな陰影で表現します。既存の仮アイコンと品名を維持し、F-004 の完了チェックは変更しません。
- ゲームロジック、注文、96個の初期在庫、操作手順、Pages のベースパスとデプロイ設定は変更しません。レイアウトの基本構成も維持します。

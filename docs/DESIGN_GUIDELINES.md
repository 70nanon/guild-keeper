# Guild Keeper デザインガイドライン

## 役割・参照資料

本書はアートディレクションと情報の見せ方を定義します。ストーリーとゲーム仕様の正本は [GAME_DESIGN.md](GAME_DESIGN.md)、機能・進捗は [FEATURES.md](FEATURES.md)、長期計画は [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) を参照してください。

企画は2026-10-22にユーザーが貼り付けた Notion 企画整理本文と今回の指示を参照しています。Notion 原ページは直接取得できなかったため、未共有の内容を補っていません。作品の仮称は「勇者の倉庫番」ですが、今回の画面タイトルは **Guild Keeper** のままです。

## アートの核

**「勇者にはならない。勇者を倉庫から支える。」小さな村の倉庫番が使う、品を見渡すためのゲームの道具。**

素材を豪華に描くより、品を探す、選ぶ、移す、支給するという仕事の記号を統一します。牧歌的な家庭用 RPG の簡潔な情報密度を目指し、木製の収納盤、持ち歩く注文帳、素朴な操作札として画面を構成します。

優先順位は、情報の判読 → PC・スマホの操作性 → 倉庫の一覧性 → 世界観です。配色や角丸だけの変更を完成とは扱いません。アイコン、セル、注文、選択品、操作が共通の形・輪郭・文字階層でつながることを確認します。

## 参考にする情報設計と権利

ユーザーが示したモンスターハンターシリーズのアイテムボックスは、**小さい記号で種類を把握し、色・記号で派生を作る情報設計**の参考です。今回その作品の画像やアイコンを取得・複製・トレースしていません。構図、形、パレット、キャラクター、ロゴをそのまま模倣しません。

今回の8品目はリポジトリ内で独自に描いた幾何形状です。画像素材、アイコンライブラリ、外部フォントは追加しません。将来外部素材を採用するときは、出典・利用条件を記録します。

## アイコンの記号体系

### 基本形：種類を輪郭で読む

第一候補はピクセルアート、または低解像度・少色数に近い記号です。今回の試作は **16×16 の整数座標、1px相当の輪郭、原則4色以内の SVG** とします。リアルな装備イラストや、絵文字の見た目には依存しません。

| 現行品目 | 独自の基本シルエット |
| --- | --- |
| 鉄の剣 | 斜めの直刃、鍔、短い柄 |
| 木の盾 | 広い肩と下端が尖った板、縦の補強 |
| 回復薬 | 幅のある丸胴瓶と栓 |
| 樫の杖 | 曲がった頭と細長い木の柄 |
| 薬草 | 左右へ開く葉と茎 |
| 鉄の兜 | 角張ったドーム、目の横溝、鼻当て |
| 魔力の雫 | 細身の封じた小瓶。回復薬の丸胴瓶と形を分ける |
| 革の靴 | 筒と横へ張り出すつま先、底 |

輪郭を無彩色にしても種類の違いを読み取れることを目指します。小さい表示と96個の混在表示で確認し、通常セルはアイコンだけにし、名前は単押しの詳細で確認します。形の識別に関する最終的なプレイヤー評価は未了であり、試作だけで F-004 を自動完了にしません。

### 実装方式と差分の作り方

`src/ui/ItemIcon.tsx` で基本形を管理し、倉庫・注文書・選択欄のすべてで同じコンポーネントを使います。SVG は `shapeRendering="crispEdges"` とし、輪郭・本体・明部・材質アクセントの4つの描画役割を CSS 変数に分離します。16px基準を2倍の32pxで倉庫・勇者・詳細・リザルトへ共通表示します。

現在の色は金属・木・革・葉・瓶の材質を示すだけです。**回復薬の色や小瓶の色に架空の属性を意味づけしません。** 既存ゲームデータは変更せず、旧データの絵文字フィールドは表示に使用しません。

将来の色違いは基本形を複製せず、パレット差分で表す案とします。紋章・印・星は基本形と別の表示レイヤーにする方針ですが、今回はそのデータや実行時の属性・レア度 API を先回りして追加しません。

## 成長と情報開示（将来方針）

**同じ品でも、倉庫番の能力で「見え方」が変わる。** これはゲームデザインと共通する原則です。

| 構想上の情報 | 表示の方針 |
| --- | --- |
| 初期に分かる大まかな種類 | 共通の中立色と種類の輪郭。詳細情報を描かない案 |
| 鑑定で分かる詳細・性能 | 詳細な基本形・細部・文字情報を開く案 |
| 属性識別で分かる属性 | 属性色を中心に、紋章・模様・ラベルも併用する |
| レア度識別で分かるレア度 | 星で示す。色や発光だけに依存しない |

これは解放順・段階数を確定する表ではありません。スキル名、色と属性の対応表、星数、開示対象、表示場所は未決定です。未識別情報を色や装飾で先に漏らさないよう、将来はゲーム上の認識状態と表示を連携します。MVP は鑑定前の情報制限を実装せず、8品目の品名と基本形を表示します。現行データにない属性色・属性紋章・星・性能値は表示しません。

## 画面の構成・情報階層

現在は上からコンパクトな冒険予定、常設の勇者インベントリ、倉庫インベントリへ分離します。ゲーム仕様は [GAME_DESIGN.md](GAME_DESIGN.md#compact-playtest-ui)、発見性の報告は [FEEDBACK.md](FEEDBACK.md) を参照してください。機能の実装と、人が操作を発見できるかの評価を分けます。

| UI 部品 | 表現と役割 |
| --- | --- |
| 倉庫全体 | 木の名札と連続した収納盤。セルを個別カードとして浮かせず、薄い仕切りで一覧を作る |
| 倉庫セル | 角の揃った平坦な区画。アイコンのみ。PCは64px角、スマホは48px角で、勇者と倉庫のセル・アイコン32px・余白を共通化。状態装飾はセル内に収める |
| 冒険帳 | 日数・目的地・短い概要・状態を常設し、右側に出発／時間／帰還／翌日の操作。詳細は明確な閉じるボタン付きの羊皮紙ダイアログで表示する |
| 勇者の枠 | 倉庫と同じセル・アイコン・余白。広い画面は8列、760px以下は4列×2段。帰還後も表示し、使用数は数字のみ。一時選別は折りたたみ、勇者パネルは画面高42％以内の内部スクロールとする |
| 選択品・操作 | 単押しから380ms後に非モーダルの詳細を開く。品名・種類・閉じる操作を置き、代替操作は「操作」内へ収納。選択されていない間は表示しない |
| 選択・移動 | 選択は内枠とチェック、移動先は破線、文言も併用。常設の操作札・成功説明・最下部の説明帯は置かない。移動先選択と失敗時のみ一時表示する |
| ドラッグ | PCは標準の追従プレビュー、スマホは長押し後の浮き上がりと指に追従する小さなプレビュー。有効な移動先と現在の対象枠を区別する |
| キーボード | 青墨のフォーカス輪郭と明るい補助縁。選択の枠と区別する |

スマホは450msの長押し前に8pxを超えて動くと通常スクロールへ譲ります。長押し後は端で300ms静止して自動スクロールし、移動先が通過中にずれないようにします。キャンセル・無効ドロップでは在庫を変更しません。タップとキーボードでも同じ移動・交換・支給を行えます。ダブル操作は350ms以内の同じ品・枠で判定し、別操作を挟むと解除します。満杯や冒険中の移動拒否は一時的なエラー表示で理由を伝えます。

ゲームの主役はインベントリです。大きな紋章・キャラクター・村風景・装飾専用の領域は追加しません。PC・スマホとも上部の短い予定→勇者→広い倉庫とします。予定詳細・左メニュー・初回案内・帰還リザルトは標準モーダルで背景操作を止め、背景クリック・閉じる・Escapeで閉じます。通常のアイテム詳細は非モーダルとしてダブル操作を妨げません。左メニューは保存状態・初期化だけとし、操作案内の再確認はヘッダーの小さい「?」へ置きます。指で探す領域を減らすための装飾は避けます。

## 今回の試作で採用した色と書体

- 背景：くすんだ草土色 `#c5c5a6`。木の名札 `#665136`、倉庫セル `#514735`、薄い区切り `#857450`。
- 帳簿：羊皮紙 `#eee3c3` と焦げ茶の文字 `#3c3021`。操作帯は木・紙をつなぐ `#d4c7a3`。
- 選択：草色の面とクリームの輪郭。数量・完了は既存の文字とチェックも使う。
- ロゴは既存の Georgia／serif、注文の見出しはローカル明朝系／serif、品名・数量・操作はシステムフォント。外部書体を読み込まない。
- アイコンは少色数と明確な輪郭を優先する。通常セルには品名を置かず、詳細・リザルトで読みます。スマホの押せる枠は44px以上を維持する。

前回の木材・羊皮紙の配色案は [旧レビュー](reviews/village-warehouse/README.md) に履歴として残します。今回の実装基準は本書と [今回の比較記録](reviews/item-symbols/README.md) です。木目・紙の汚れ・陰影を描き込みすぎず、発光、強い光沢、巨大な金具、丸いカードの群れ、装飾専用の空白を使いません。

- ストーリー・報告書・スキル・設備の実装や完了を、このデザイン試作の成果と混同しない。


## 2026-10-23の表示・演出

初回案内は閉じた記録を保存し、常時の説明ラベルを増やしません。出発は確認不要の短いセリフと所要時間で伝え、4.5秒で閉じます。強い発光・常時アニメーションは追加しません。

帰還リザルトは羊皮紙の受領帳として、コメント→返却／戦利品／使用数→空き／選択数と確定→品の一覧→使用した消耗品を配置します。受領済みの品も履歴として示し、保持品と区別します。リザルトを閉じることと入庫確定を分け、満杯時は倉庫へ戻って作業できます。色だけでなくチェック・文言でも状態を示します。
